# Nosso álbum — versão leve para GitHub Pages

## MUITO IMPORTANTE

**NÃO envie o arquivo `.zip` para o GitHub!** Extraia o ZIP no computador primeiro.

1. Entre no repositório `mauroruan2004-code/nosso-album`.
2. Clique **Add file → Upload files**.
3. No arquivo ZIP descompactado, selecione o `index.html`, `videos.html`, `.nojekyll`, `README.md` e as pastas `fotos` e `videos`, arraste TUDO para a página de upload.
4. Se falhar ao enviar tudo junto, faça **dois envios**: primeiro `index.html`, `videos.html`, `README.md`, `.nojekyll` e a pasta `fotos`; depois a pasta `videos`. Não coloque as pastas dentro de uma outra pasta no GitHub.
5. Confirme **Commit changes** em cada envio.
6. Em **Settings → Pages**, escolha **Deploy from a branch → main → /(root) → Save**.

Os vídeos foram compactados para carregarem melhor no celular. O álbum contém **40 fotos e 32 vídeos**, com a seção de nossas músicas via YouTube (requer internet).

⚠️ Este álbum contém imagens pessoais. O GitHub Pages é acessível publicamente.
